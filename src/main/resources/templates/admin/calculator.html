Guide d'utilisation Excel-like
Raccourcis clavier
  • ↑↓←→ : Navigation entre cellules
  • Entrée : Aller à la cellule du dessous
  • F2 ou double-clic : Éditer la cellule
  • Échap : Annuler l'édition
Formules et fonctions
  • Arithmétique : =A1+B1, =A1*B1, =A1/B1
  • Fonctions : SUM, AVERAGE, MAX, MIN, COUNT
  • Logique : IF(condition, vrai, faux)
  • Texte : CONCATENATE(texte1, texte2)
  • Plages : A1:B5 pour plusieurs cellules
